# 01 - Data Collection

Loads the raw dataset (`Loan_default.csv`, 255,347 loan applications) and takes a first look: row/column counts, missing values, and the target class balance (`Default`).

## How to run
```bash
pip install pandas
jupyter notebook notebook.ipynb
```

## Files
- `notebook.ipynb` — loads and inspects the data
- `data/Loan_default.csv` — raw dataset (not modified by this notebook)

Printed overview only.
