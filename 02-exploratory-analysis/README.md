# 02 - Exploratory Data Analysis

Explores the raw data: summary statistics, a correlation heatmap, and charts of the target class balance and age distribution.

## How to run
```bash
pip install pandas numpy matplotlib seaborn
jupyter notebook notebook.ipynb
```

## Input
`../01-data-collection/data/Loan_default.csv`

## Output
- `output/correlation_heatmap.png`
- `output/exploration_charts.png`
